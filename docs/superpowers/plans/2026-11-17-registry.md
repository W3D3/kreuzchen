# Questionnaire Registry Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A headless, containerized registry server that serves each practice its entitled questionnaire definitions behind username + key, and an app screen that installs, updates and removes them by click, with registry definitions locked against editing.

**Architecture:** New workspace crate `crates/registry` (axum server + `key` subcommand) validates definitions with `kreuzchen-engine` at startup and serves two authenticated endpoints. The Tauri backend gains a second definitions folder `registry/` (locked entries), a registry client module, and commands; the Svelte frontend gains a registry screen reachable from the start screen.

**Tech Stack:** Rust (axum 0.8, tokio, argon2, rand, base64, sha2, serde_norway), Tauri 2 backend with reqwest 0.13 (rustls), Svelte 5 + TypeScript, Docker.

**Spec:** `docs/superpowers/specs/2026-11-17-registry-design.md`

## Global Constraints

- The repository is public: no code, test, doc, commit or PR names a specific questionnaire or customer. Tests use invented definitions only (e.g. `examples/definitionen/beispiel.yaml`, `beispiel_normen.yaml`, or inline YAML with ids like `fragebogen_a`).
- Commit with `git commit --no-gpg-sign`; end messages with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- `main` takes squash or rebase merges only; never force-push.
- Lockfiles: `npx -y npm@11 i …` for npm; cargo at `~/.cargo/bin/cargo`. Building `src-tauri` needs `nix develop -c …`.
- Fingerprint = `definitions::hash` (SHA-256 of file bytes, lowercase hex). The server must produce the identical string.
- Every server request except `GET /healthz` needs HTTP Basic auth. Missing, unknown user, wrong key → identical `401`, empty body. Unknown or not-entitled id → identical `404`, empty body. All responses `Cache-Control: no-store`. Logs never contain keys.
- Nothing on a practice computer changes without a click. No background polling of the registry.
- UI copy is German, verbatim from the spec where given: „Fragebögen aus der Registry“, „Verbinden“, „Trennen“, „Ändern“, „Installieren“, „Aktualisieren“, „Entfernen…“, „Nach Änderungen suchen“, „Registry nicht erreichbar“, „Lokale Kopie durch die Version aus der Registry ersetzen?“, state labels „verfügbar“, „aktuell“, „neue Version verfügbar“, „nicht mehr auf dem Server“.

## Review Focus

1. A URL typed with a trailing slash, with a path, or without `https://` → the app normalizes it (`kreuzchen.wedenig.dev` and `https://kreuzchen.wedenig.dev/` both work). Test in Task 5.
2. Username or key pasted with surrounding whitespace or a trailing newline → trimmed before saving. Test in Task 5.
3. A definition id that is not a safe file name (`../x`, `a/b`, `con:x`) on the server → the server refuses to start; the app refuses to write it. Tests in Tasks 1 and 5.
4. Server unreachable or slow → the app answers within 10 s with „Registry nicht erreichbar“ instead of hanging. Test in Task 5 (closed port).
5. Download whose bytes do not match the announced hash, or that fails to load → the installed file is unchanged. Test in Task 5.

### Task 5: Registry client in the app backend

**Files:**
- Create: `src-tauri/src/registry.rs`
- Modify: `src-tauri/src/lib.rs` (register commands), `src-tauri/src/commands.rs`, `src-tauri/Cargo.toml` (`reqwest = { version = "0.13", default-features = false, features = ["rustls", "json"] }`, matching the lockfile; dev-dependency `kreuzchen-registry` by path, plus `tokio` with `macros` and `rt-multi-thread`)
- Test: tests inside `registry.rs` (`#[cfg(test)]`) that start `kreuzchen_registry::router` on `127.0.0.1:0`

**Interfaces:**
- Consumes: `scan`, `check_name`, `load_text`, `hash`, `write_atomic`, `Paths` from Task 4; `router`, `load` from Tasks 1–2 (tests only).
- Produces:
  - `#[derive(Serialize, Deserialize)] pub struct Connection { pub url: String, pub user: String, pub key: String }`; `pub fn normalize_url(input: &str) -> Result<String, String>` (adds `https://` when no scheme is given, strips the trailing `/`, rejects anything that is not http/https).
  - `pub fn load_connection(app_data: &Path) -> Option<Connection>`, `pub fn save_connection(app_data: &Path, c: &Connection) -> Result<(), String>` (trims user and key), `pub fn clear_connection(app_data: &Path)`.
  - `#[derive(Serialize, Deserialize)] pub struct RemoteEntry { id, title, version, hash }` (all `String`).
  - `#[serde(rename_all = "snake_case")] pub enum RowState { Available, Current, Update, Gone }`; `pub struct Row { pub id: String, pub title: String, pub state: RowState, pub file: Option<String> }`.
  - `pub fn rows(remote: Option<&[RemoteEntry]>, installed: &[DefinitionEntry]) -> Vec<Row>`: pure; `installed` is the registry folder's entries. With `None` (offline or disconnected) it returns only installed entries, each with state `Current`; the frontend then shows „Registry nicht erreichbar“ and only **Entfernen…** instead of the state label.
  - `pub async fn fetch_list(c: &Connection) -> Result<Vec<RemoteEntry>, String>` and `pub async fn install(c: &Connection, paths: &Paths, id: &str, replace_local: bool) -> Result<InstallOutcome, String>`, where `pub enum InstallOutcome { Installed, NeedsReplaceConfirm }`. `install` returns `NeedsReplaceConfirm` when a local definition has this id and `replace_local` is false. It writes `registry/<id>.yaml` only after these checks:
    - the id passes `check_name(&format!("{id}.yaml"), YAML)`;
    - the hash header equals `hash(bytes)` and the list entry;
    - `load_text` succeeds and the loaded `def.id` equals `id`.

    With `replace_local`, it deletes the local file first.
  - Client timeout 10 s; any network error → `Err("Registry nicht erreichbar")`; 401 → `Err("Benutzername oder Schlüssel falsch")`.
  - Commands: `registry_connection() -> Option<{url, user}>` (never returns the key), `registry_connect(url, user, key) -> Result<(), String>` (fetches the list first, saves only on success), `registry_disconnect()`, `registry_rows() -> Result<Vec<Row>, String>`, `registry_install(id, replace_local) -> Result<InstallOutcome, String>`, `registry_remove(file) -> Result<(), String>` (deletes from `registry/` only).

- [ ] **Step 1: Write the failing tests:**
  - `normalize_url_cases`:
    - `"kreuzchen.wedenig.dev"` → `"https://kreuzchen.wedenig.dev"`;
    - `"https://x.y/"` → `"https://x.y"`;
    - `"ftp://x"` → Err.
  - `save_connection_trims`: user `" praxis \n"` and key `"abc\n"` are stored as `"praxis"` and `"abc"`.
  - `rows_states`:
    - remote a (hash h1), b, c; installed a (h1), b (h0), d → a `Current`, b `Update`, c `Available`, d `Gone`;
    - `rows(None, installed)` lists a, b and d only.
  - `install_end_to_end`: start the registry router with an invented definition → fetch_list returns it, install writes `registry/fragebogen_a.yaml` with the served bytes.
  - `install_asks_before_replacing_local`: the local folder holds the same id → `NeedsReplaceConfirm` and nothing written; with `replace_local = true`, the local file is gone and the registry file exists.
  - `install_keeps_old_file_on_bad_hash`: a hand-built axum route serves bytes with a wrong `X-Kreuzchen-Hash` → Err, and the previously installed file is byte-identical.
  - `wrong_key_message` and `unreachable_is_reported_quickly`: connect to a closed port → Err „Registry nicht erreichbar“ in under 11 s.
- [ ] **Step 2: Run** `nix develop -c cargo test -p kreuzchen registry` → FAIL.
- [ ] **Step 3: Implement** `registry.rs` and the commands. Store the connection as `app_data/registry.json` with `write_atomic`.
- [ ] **Step 4: Run** → PASS; `nix develop -c cargo clippy -p kreuzchen --all-targets` clean.
- [ ] **Step 5: Commit** `feat(app): registry client and commands`.
